Available Agent Tools

openart_generate_image

Generates high-resolution raster images using Seedream 5.0, FLUX.1, or SDXL with custom aspect ratios.

Arguments: { prompt: string, model?: string, aspect_ratio?: "1:1" | "16:9" | "9:16" }
openart_generate_video

Produces 1080p motion video clips from image anchors or text prompts with camera direction.

Arguments: { image_url: string, motion_path: "Pan Left" | "Zoom In" | "Orbit", duration: 5 | 10 }
openart_topaz_upscale

Enhances image resolution up to 8x with facial restoration and texture reconstruction.

Arguments: { asset_url: string, multiplier: 2 | 4 | 8, face_restore: boolean }
